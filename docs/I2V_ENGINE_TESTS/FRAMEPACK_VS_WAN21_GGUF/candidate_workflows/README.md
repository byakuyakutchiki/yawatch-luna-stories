# Candidate Workflows

Ces fichiers ne doivent pas etre queues aveuglement.

Ils servent de point de depart pour reconstruire ou adapter les workflows dans ComfyUI apres installation des custom nodes.

Regle:

1. Charger un exemple officiel du custom node quand il existe.
2. Comparer les noms de noeuds avec `/object_info`.
3. Adapter le workflow candidat.
4. Exporter le workflow final depuis ComfyUI.
5. Archiver le workflow final avec le MP4 et le rapport.

Les workflows candidats contiennent le prompt YAWatch et les parametres de test, mais les noms de noeuds peuvent devoir etre ajustes selon la version installee.
