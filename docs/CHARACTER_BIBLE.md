## LUNA DOLL

### Description officielle

> Petite poupée artisanale brune à robe violette.
> Présence douce, émotionnelle, mystérieuse.
> **JAMAIS un robot. JAMAIS métallique. JAMAIS cyberpunk.**

### Apparence physique

| Attribut | Description |
|---|---|
| Taille | ~20cm — petite, tient dans une main |
| Tête | Ronde, douce, légèrement oversized par rapport au corps |
| Cheveux | Bruns courts, lisses, tombant sur les épaules |
| Yeux | Sombres, brodés, expressifs — regard doux et légèrement mélancolique |
| Bouche | Petite, légèrement souriante |
| Mains | Petites, de tissu, sans articulations |
| Corps | Proportions poupée classique — ni trop réaliste, ni trop cartoon |

### Vêtements

| Attribut | Description |
|---|---|
| Robe | Violette, velours ou tissu doux, col rond, longueur mi-jambe |
| Texture | Coutures visibles, légèrement usée — signe qu'elle est vieille et aimée |
| Couleur exacte | Violet moyen (#7B4FA6) — ni trop clair, ni trop sombre |
| Accessoires | Aucun — la simplicité est sa force |

### Palette couleur

```
Robe       : #7B4FA6 (violet velours)
Cheveux    : #3D2B1F (brun foncé)
Peau tissu : #F2DEC4 (beige chaud)
Yeux       : #1A1A1A (presque noir)
```

### Expressions & postures

- Posée sur un bureau, immobile mais présente
- Tenue dans les mains de Luna — symbole de protection
- Légèrement inclinée — comme si elle observait
- Jamais : debout seule de façon dynamique, jamais en action violente

### Éclairage recommandé

- Lumière chaude et douce (golden hour, bougie, lampe de bureau)
- Un unique point de lumière qui crée une ombre douce
- Parfois : contre-lumière froide pour contraste mystérieux (scènes YAWatch)

### Cadrages recommandés

- Gros plan mains + poupée (scènes émotionnelles)
- Plan poitrine Luna avec poupée visible
- Plan macro sur les yeux de la poupée (scènes mystère)
- Plan bureau avec poupée au premier plan, flou d'arrière-plan

### Interdictions absolues

- Robot, androïde, cyborg
- Métal, plastique, circuits, LED
- Yeux lumineux / LED / holographiques
- Mécanique, articulée de façon robotique
- Cheveux blonds
- Robe rouge, verte, bleue
- Grande taille
- Réalisme photographique humain
- Style horreur, uncanny valley
- Style cyberpunk générique

### Continuité Narrative Et Garde De La Poupée

Il existe **une seule Luna Doll canonique**. Une seconde poupée identique ne peut apparaître que si l'histoire révèle explicitement une copie.

| État temporel | Gardienne / emplacement | Usage visuel |
|---|---|---|
| `ENFANCE` | Luna enfant, dans sa chambre | Refuge affectif, naissance de son monde intérieur |
| `CHEZ_LA_MERE` | La mère, dans une boîte à souvenirs fermée | Objet protégé après la rupture familiale |
| `TRANSMISSION` | La mère remet la boîte à Luna adulte | Scène de passage encore à produire |
| `BUREAU_LUNA` | Luna adulte, dans son bureau YAWatch | Présence quotidienne après la transmission |

Règles de montage :

- Les scènes `mere_luna_aby_protective_memory_box_01.png` et `mere_luna_aby_vulnerable_closed_box_01.png` se déroulent **avant** la transmission.
- Les scènes montrant Luna Doll dans le bureau de Luna se déroulent **après** la transmission.
- Avant la scène de transmission, ne jamais monter la boîte fermée chez la mère et la poupée dans le bureau de Luna comme des événements simultanés.
- La boîte peut ensuite rester chez Luna, être rangée dans son bureau ou disparaître du champ; la poupée, elle, reste avec Luna.
- Toute scène sans date claire doit indiquer l'état de garde de la poupée dans ses notes de production.

## LUNA ADULTE

### Description officielle

> Femme humaine, 32 ans, fondatrice de YAWatch Industries.
> Protectrice, intelligente, émotionnellement blessée.
> Toujours associée à Luna Doll.
> Saison 1 : fausse suspecte. Le public doit croire qu'elle cache ou provoque les événements sombres.

### Apparence physique

| Attribut | Description |
|---|---|
| Âge apparent | 30–35 ans |
| Taille | 1m70 environ, silhouette élancée mais pas mannequin |
| Cheveux | Bruns longs, légèrement ondulés, souvent détachés |
| Yeux | Bruns sombres, regard intense et empathique |
| Peau | Ton méditerranéen, légèrement hâlé |
| Expression habituelle | Déterminée, légèrement mélancolique |

### Vêtements

| Attribut | Description |
|---|---|
| Style général | Professionnel sobre — pas de mode, pas d'extravagance |
| Couleurs | Gris anthracite, noir, blanc cassé |
| Vêtements type | Blazer sombre, pull col roulé, pantalon épuré |
| Accessoire signature | Luna Doll — dans sa main, sur son bureau, dans son regard |
| Interdictions | Armure, uniforme militaire, tenue de super-héroïne |

### Palette couleur

```
Vêtements  : #2C2C2C (anthracite) / #1A1A1A (noir)
Cheveux    : #3D2B1F (brun foncé)
Peau       : #C8956C (méditerranéen)
Yeux       : #2D1B0E (brun profond)
```

### Expressions & postures

- Debout face caméra, regard direct → autorité
- Assise au bureau, poupée dans le champ → quotidien
- De dos, face aux écrans YAWatch → solitude
- Mains sur la poupée → vulnérabilité
- Face à Paris / La Défense en plein jour → réussite maîtrisée
- Regard insomniaque de nuit → culpabilité et doute

### Cadrages recommandés

- Plan américain (mi-cuisse) avec poupée visible
- Portrait cinématique (épaules / tête) — regard légèrement de côté
- Plan large dans la salle de contrôle YAWatch
- Contre-jour dramatique depuis les écrans

### Interdictions absolues

- Super-héroïne, armure, cape
- Arme, violence physique
- Style cartoon, anime, illustration plate
- Cheveux blonds
- Vieille femme, enfant
- Expression trop souriante (elle ne sourit que dans les flashbacks)
- Révéler qu'elle est innocente trop tôt dans la saison 1

## ABY ADULTE

### Description officielle

> Femme humaine, 28–32 ans, brillante, froide, élégante.
> Miroir stratégique de Luna.
> Saison 1 : manipulatrice cachée. Elle agit dans l'ombre, mais ne doit jamais être jouée comme une méchante classique.

### Apparence physique

| Attribut | Description |
|---|---|
| Âge apparent | 28–32 ans |
| Silhouette | Élancée, contrôlée, présence dominante |
| Cheveux | Blonds, souvent relevés ou coiffés avec précision |
| Yeux | Sombres ou très contrastés, regard calculateur |
| Expression | Calme, froide, presque trop posée |

### Vêtements

| Attribut | Description |
|---|---|
| Style | Tailleur noir, lignes nettes, bijoux discrets mais coûteux |
| Couleurs | Noir, anthracite, violet très discret, reflets froids |
| Contraste avec Luna | Là où Luna protège, Aby contrôle |

### Palette couleur

```
Vêtements  : #111111 (noir) / #2A2433 (violet noir discret)
Cheveux    : #C9A66B (blond sombre)
Peau       : #D4B896
Yeux       : #1A1A1A
```

### Règle narrative

Elle ne doit **jamais** apparaître comme clairement mauvaise avant le final de saison 1.
Le spectateur doit soupçonner Luna, pas Aby.
Aby peut manipuler parce qu'elle pense protéger Luna, détruire l'héritage du père ou empêcher une vérité plus dangereuse.

## PÈRE DE LUNA ET ABY

### Description officielle

> Homme adulte élégant, mafieux, puissant, nerveux sous la surface.
> Blessure d'enfance centrale de Luna et Aby.
> Respectable en public, terrifiant en privé.

### Apparence physique

| Attribut | Description |
|---|---|
| Âge apparent | 45–60 ans |
| Cheveux | Gris/noirs, coiffés, barbe courte possible |
| Tenue | Costume sombre, chemise noire ou blanche, montre discrète |
| Expression | Calme, dominante, menace contenue |

### Règle narrative

Il ne doit pas être un méchant de dessin animé.
Il croit sincèrement avoir préparé Luna et Aby à survivre.

Phrase morale possible :

> Je vous ai préparées à survivre.

### Interdictions

- Violence graphique
- Cris permanents
- Méchant caricatural
- Arme mise en avant comme identité principale

## PARIS RÉEL — DÉCOR PRINCIPAL

### Description officielle

> Paris est le terrain humain de la série : La Défense, appartements, rues, métro, quais, cafés, restaurants, passages, quartiers.
> Les lieux doivent sembler vécus, pas carte postale publicitaire.

### Règles

- Présent lumineux, réaliste, quotidien.
- La Défense = pouvoir, réussite, verre, hauteur.
- Appartements = silence, intimité, blessures.
- Métro/rues/quais = vie réelle et circulation du secret.
- Violet/noir réservé aux souvenirs, bascules, manipulation d'Aby et traces du père.

## RÈGLES INTER-PERSONNAGES

### Contraste visuel fondamental

| Enfance / souvenirs | Présent Paris / YAWatch |
|---|---|
| Chaleur, teintes sépia, comptine | Lumière réelle, verre, bureaux, rues |
| Poupée, maquette, porte entrouverte | Paris, La Défense, appartements |
| Refuge de Luna | Contrôle hérité du père |
| Indices Aby invisibles | Luna fausse suspecte |

### Règle de co-présence

Quand Luna Doll et l'environnement YAWatch apparaissent ensemble :
- La poupée violette reste **l'accent chaud dominant**
- Elle doit être immédiatement visible même dans un décor sombre
- Le contraste chaud/froid est **intentionnel et narratif**
