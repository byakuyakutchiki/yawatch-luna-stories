# Identite Sonore - Comptine Brisee

## Reference Emotionnelle

L'inspiration citee est l'emotion provoquee par "Little Susie" : pas la chanson elle-meme, mais ce qu'elle fait ressentir.

Elements emotionnels a retenir :

- innocence perdue ;
- enfance brisee ;
- tristesse silencieuse ;
- drame cache derriere une histoire simple ;
- contraste entre une voix d'enfant et une ambiance sombre.

## Regle Juridique / Creative

Ne pas copier la melodie, les paroles ou l'arrangement d'une chanson existante.

Creer un motif original qui evoque :

- comptine ;
- souvenir ;
- douceur ;
- malaise progressif.

## Motif Luna / Aby

Le motif doit avoir deux versions :

### Version Luna

- piano doux ;
- voix enfant tres legere ;
- lumiere chaude ;
- tempo lent mais rassurant ;
- sensation de refuge.

### Version Aby

- meme motif ralenti ;
- notes espacees ;
- respiration froide ;
- reverb plus longue ;
- sensation de controle et de souvenir abime.

## Idee Narrative

Luna et Aby ne se souviennent pas de la meme enfance.

Luna entend une comptine de refuge.

Aby entend la meme comptine comme une preuve de ce qui s'est vraiment passe.

Cette difference devient un indice de saison 1.

## Utilisation Par Episode

### Teaser

Le motif apparait pour la premiere fois, tres simple.

### Episodes 1-3

Le motif revient par fragments :

- 2 notes dans une chambre ;
- une voix enfant presque inaudible ;
- piano quand la photo apparait ;
- version froide quand Aby apparait.

### Final Saison 1

Le motif complet revient, mais dans la version Aby.

Le spectateur comprend que la comptine n'etait pas seulement le souvenir de Luna.

## Consigne Musique

Prompt possible pour generer une musique originale :

```text
Create an original cinematic lullaby theme for an emotional psychological thriller set in Paris. Slow fragile piano, distant childlike vocal texture without lyrics, warm nostalgic beginning, gradually darker undertone, subtle strings, intimate sadness, mystery, no horror jump scare, no imitation of existing songs, 60 seconds.
```

Version sombre :

```text
Create a darker variation of the same original lullaby theme. Slower tempo, sparse piano notes, cold reverb, distant childlike hum without lyrics, emotional tension, tragic memory, restrained psychological thriller mood, no horror cliche, no imitation of existing songs.
```
