# Teaser S01E00 - Plan 30 A 60 Secondes

## Objectif

Créer un premier teaser cinematique qui donne envie de regarder la saison 1.

Le teaser ne doit pas expliquer YAWatch. Il doit poser une question :

> Quel secret cache Luna ?

Ou plus precisement :

> Pourquoi Luna connait-elle des choses qu'elle ne devrait pas connaitre ?

## Phrase Centrale Possible

Options :

- Tout a commence bien avant YAWatch.
- Certaines blessures ne disparaissent jamais.
- Luna savait des choses qu'elle n'aurait jamais du savoir.
- Le vrai secret n'etait pas dans la machine. Il etait dans l'enfance.

Recommandation :

> Tout a commence bien avant YAWatch.

Simple, mysterieux, humain.

## Structure 60 Secondes

### 0-10 s - Paris Normal / Reussite

Images :

- La Defense jour.
- Tour YAWatch.
- Bureau lumineux.
- Luna adulte calme.
- Paris vivant.

Emotion :

- succes ;
- controle ;
- elegance ;
- vie normale.

Voix possible :

> Aujourd'hui, tout le monde connait Luna.

### 10-20 s - Faille Intime

Images :

- photo ancienne retournee ;
- Luna Doll ;
- chambre enfant ;
- maquette ;
- main d'enfant ;
- voix enfant en arriere-plan.

Voix possible :

> Mais personne ne sait vraiment d'ou elle vient.

### 20-35 s - Le Pere / Menace

Images :

- pere dans bureau sombre ;
- diner tension ;
- appel nuit Tour Eiffel ;
- porte entrouverte ;
- silhouette ou archive ;
- Aby enfant tres breve.

Voix possible :

> Dans certaines familles, on n'apprend pas a aimer. On apprend a survivre.

### 35-50 s - Acceleration / Faux Soupcon Luna

Images :

- Luna adulte de nuit ;
- Aby adulte regard froid ;
- Malik seul ;
- interface YAWatch ;
- photo de famille floue ;
- jeton noir ;
- plans rapides de Paris nuit.

Voix possible :

> Et quand Luna a commence a savoir ce que personne ne disait... il etait deja trop tard.

### 50-60 s - Silence / Titre

Images :

- silence sur photo retournee ;
- son d'une comptine ralentie ;
- le jeton noir pres de la maquette ;
- cut noir.

Texte final :

```text
LUNA
Tout a commence par un secret.
```

## Version 30 Secondes

0-6 s :

- La Defense / Luna adulte / succes.

6-12 s :

- photo retournee / Luna Doll / chambre enfant.

12-20 s :

- pere / Aby / Malik / interface.

20-27 s :

- montage rapide, Luna soupconnee.

27-30 s :

- silence, jeton noir, titre.

## Plans De Mouvement Necessaires

Le teaser doit eviter l'effet diaporama.

Mouvements recommandes :

- push-in lent vers photo retournee ;
- travelling lateral dans bureau YAWatch ;
- zoom tres lent sur Luna Doll ;
- pan vertical sur La Defense ;
- camera epaule discrete sur Malik ;
- reflet Aby dans vitre ;
- focus pull sur jeton noir ;
- micro-mouvement lumiere/pluie/fenetre.

## Voix

Voix necessaires pour le teaser :

1. Narrateur principal.
2. Voix enfant tres courte, type comptine / souvenir.
3. Luna adulte, optionnel.
4. Aby adulte, optionnel.

Regle :

Ne pas trop faire parler les personnages dans le teaser.

Le teaser doit etre porte par :

- le narrateur ;
- la musique ;
- les silences ;
- les plans ;
- une phrase choc.

## Identite Sonore

La musique doit avoir un motif recurrent.

Inspiration emotionnelle :

- innocence perdue ;
- enfance brisee ;
- tristesse silencieuse ;
- contraste entre voix enfant et monde sombre.

Ne pas copier une chanson existante.

Creer un motif original :

- 3 a 5 notes de piano ;
- voix enfant tres douce en texture ;
- comptine lente ;
- puis version deformee / ralentie dans les scenes sombres.
